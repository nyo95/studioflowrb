## Locked invariants

- Project content mutates only while the owning project is ACTIVE.
- Imported price baseline is immutable; Custom Cost Components have no baseline
  and therefore no revert.
- Component Group is optional and has no meaning outside grouping Cost Components.
- BQ reads Master Data Units through a public contract and persists snapshots,
  never a cross-app foreign key.
- BQ owns deletion requests; approval requires
  `bq.project-deletion.approve` and hard deletion plus audit is transactional.
- Cross-app promotion is coordinated above both apps; neither app imports the
  other's internal runtime.
